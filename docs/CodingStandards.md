# Coding Standards

## Purpose
This document sets a shared bar for code quality and style across TypeScript (web/mobile) and .NET (backend) so a mixed-experience team (1 senior, 2 junior developers) produces consistent, reviewable code.

## Scope
Covers code-level conventions: formatting, structure, preferred patterns, and anti-patterns to avoid.

**Out of scope:** naming rules for files/classes/variables (see [NamingConventions.md](NamingConventions.md)) and architectural decisions (see [Architecture.md](Architecture.md)).

## When to Update This Document
- The team agrees on a new pattern or convention.
- Linter/formatter rules change.
- Recurring feedback in code reviews points to a gap not yet documented.
