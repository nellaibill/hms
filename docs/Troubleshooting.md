# Troubleshooting

## Purpose
This document is a practical, symptom-first guide for diagnosing and fixing common local development and environment problems, so juniors aren't blocked waiting on the senior developer for repeat issues.

## Scope
Covers common operational and dev-environment problems (setup failures, build errors, connectivity issues) and their resolutions.

**Out of scope:** tracked product bugs (see [BugFixes.md](BugFixes.md) and [KnownIssues.md](KnownIssues.md)).

## When to Update This Document
- Whenever a developer hits a non-obvious problem and finds a fix, especially if it's likely to recur for others.
