# Known Issues

## Purpose
This document tracks currently known, unresolved issues and limitations so the team and stakeholders are not surprised by them, and so they aren't rediscovered repeatedly.

## Scope
Covers open issues or accepted limitations for the current MVP scope.

**Out of scope:** resolved bugs (see [BugFixes.md](BugFixes.md)) and intentional future-scope gaps that were never planned for MVP (see [FeatureRequests.md](FeatureRequests.md)).

## When to Update This Document
- A new known issue or limitation is discovered.
- An existing known issue is resolved (remove it from here and add it to [BugFixes.md](BugFixes.md)).

## Recommended Sections
- Known Issue Entry Template
- Current list of open issues
