# Security

## Purpose
This document is the central reference for security practices and policies that apply across the whole system, beyond authentication and authorization specifics.

## Scope
Covers data protection, secrets management, input validation policy, and dependency/vulnerability management.

**Out of scope:** authentication mechanics (see [Authentication.md](Authentication.md)) and role/permission rules (see [Authorization.md](Authorization.md)) — this document cross-links to both.

## When to Update This Document
- After a security review or audit.
- After a security incident or near-miss.
- When a new compliance requirement (e.g., handling of patient data) is introduced.

## Recommended Sections
- Overview
- Data Protection (patient data handling considerations)
- Secrets Management
- Input Validation Policy
- Dependency & Vulnerability Management
- Reporting a Security Issue
- Compliance Considerations
