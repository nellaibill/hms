# Authentication

## Purpose
This document explains how users prove their identity to the system across web, mobile, and the backend API, so the mechanism is understood and applied consistently.

## Scope
Covers the authentication mechanism, token/session strategy, and how each client integrates with it.

**Out of scope:** roles/permissions (see [Authorization.md](Authorization.md)) and broader security practices (see [Security.md](Security.md)).

## When to Update This Document
- The authentication provider or mechanism changes.
- Token lifetime, refresh, or storage strategy changes.
- A new client (web/mobile) integrates authentication for the first time.
