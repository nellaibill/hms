# Feature Requests

## Purpose
This document is a lightweight backlog of proposed features and enhancements beyond the current MVP scope, so ideas are captured without derailing the MVP or requiring a full project-management tool.

## Scope
Covers proposed, not-yet-approved features and enhancements, including deferred architectural approaches noted in [Architecture.md](Architecture.md) (e.g., microservices, event-driven patterns) if they resurface as requests.

**Out of scope:** current sprint/in-progress work (tracked wherever the team manages active tasks) and resolved items (once built, remove or move to [ReleaseNotes.md](ReleaseNotes.md)).

## When to Update This Document
- Whenever a new feature idea or enhancement is proposed.
- Whenever a request's status changes (e.g., approved, rejected, built).

## Recommended Sections
- Feature Request Entry Template
- Current list of requests
