# Logging

## Purpose
This document defines logging conventions so logs are consistent, useful, and searchable across all modules and both frontend applications.

## Scope
Covers log levels, structured logging format, and what should/should not be logged.

**Out of scope:** how errors are handled and surfaced to users (see [ErrorHandling.md](ErrorHandling.md)).

## When to Update This Document
- The logging library or structured format changes.
- A new log level or correlation convention is introduced.
- Sensitive data is found in logs and a rule is added to prevent recurrence.
