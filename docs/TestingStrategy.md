# Testing Strategy

## Purpose
This document defines the testing approach and expectations across frontend and backend, scoped appropriately for an MVP built by a small team.

## Scope
Covers test types (unit, integration, architecture), tooling, and coverage expectations.

**Out of scope:** CI pipeline mechanics that run these tests (see [Deployment.md](Deployment.md) and `cicd/scripts/`).

## When to Update This Document
- Test tooling changes.
- Coverage expectations change.
- A new test type is introduced (e.g., end-to-end tests, post-MVP).
