# API Standards

## Purpose
This document defines conventions for designing and consuming HTTP APIs across all backend modules, so frontend integration (web and mobile) stays predictable regardless of which module an endpoint belongs to.

## Scope
Covers REST conventions, request/response shape, status codes, error format, versioning, and pagination.

**Out of scope:** business logic of individual endpoints, authentication mechanics (see [Authentication.md](Authentication.md)), and authorization rules (see [Authorization.md](Authorization.md)).

## When to Update This Document
- A new cross-cutting API convention is adopted (e.g., a new pagination pattern).
- The API versioning strategy changes.
- The standard error response shape changes (coordinate with [ErrorHandling.md](ErrorHandling.md)).
