# HMS Frontend

Contains the three frontend workspaces for the Hospital Management System:

- [`web/`](web/README.md) — React web application
- [`mobile/`](mobile/README.md) — React Native mobile application
- [`shared/`](shared/README.md) — Cross-platform TypeScript code shared by both apps

See [docs/Architecture.md](../docs/Architecture.md) and [docs/FolderStructure.md](../docs/FolderStructure.md) for the full rationale behind this layout.
